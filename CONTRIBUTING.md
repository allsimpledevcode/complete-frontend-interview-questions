# Contributing Guide

Thank you for your interest in contributing to this repository!  
Our goal is to create a high-quality collection of **frontend interview questions** that helps developers prepare effectively.

## How You Can Contribute
You can help in many ways:
- Add new frontend interview questions (with or without answers).
- Improve or correct existing questions/answers.
- Add examples or explanations for tricky concepts.
- Fix typos, formatting, or broken links.
- Suggest new categories or ways to organize content.

## Contribution Process
1. **Fork** the repository to your account.
2. **Clone** your fork locally:
   ```bash
   git clone git@github.com:allsimpledevcode/complete-frontend-interview-questions.git
   ```
3. Create a new branch for your changes:
   ``` bash
   git checkout -b feature/add-new-questions
   ```
4. Commit your changes with a clear message:
``` bash
git commit -m "Add: new CSS questions about flexbox"
```
5. Push your branch:
``` bash
git push origin feature/add-new-questions
```
6. Open a Pull Request (PR) to the main branch.
