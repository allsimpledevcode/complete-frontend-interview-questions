# Complete Frontend Interview Questions

A curated collection of frontend interview questions covering Data Structures & Algorithms (DSA), JavaScript, React, UI coding challenges, and system design.

---

##  What’s Inside

- **Data Structure & Algo** — Questions centered on foundational algorithms and data structures.
- **JavaScript Questions** — Core JS topics including ES6+, async behavior, closures, and more.
- **UI Coding Questions** — Practical exercises focusing on UI implementation and interaction.
- **Oral / System Design Questions** — Conceptual prompts to test architecture and design thinking.

---

##  Getting Started

1. **Browse** the questions organized in their respective folders.
2. **Pick a section** to practice—whether it's DSA, JS, React, or system design.
3. **Use it for** interview prep, self-assessment, or peer mentoring.
